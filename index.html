常见问题

第一次安装和使用的小提示

1. 苹果电脑（Mac）提示“无法验证开发者”或“已损坏”怎么办？

因为软件目前没有购买苹果官方的年度认证签名，首次打开时请在「访达 → 应用程序」里右键点击 EchoBox → 打开；如果还是提示已损坏，打开 Mac 的“终端”应用，复制粘贴下面这行命令并回车即可正常打开： xattr -cr /Applications/EchoBox.app

2. Windows 电脑提示“Windows 已保护你的电脑”怎么办？

独立开发的小工具在没有购买微软付费认证前都会弹出这个提醒。只需点击弹窗里的「更多信息」，再点击底部的「仍要运行」就能正常启动。

3. Pro 激活码怎么使用？以后换电脑怎么办？

在软件右上角或「设置 → 激活 Pro」里粘贴收到的激活码，点一下就能立刻解锁。激活码永久有效，以后重装系统或换新电脑，输入同一串激活码就能恢复 Pro 权限。

4. 《合规与免责声明》EchoBox 会提供或保存网上的文件或链接吗？

EchoBox 为纯本地规则解析与信息聚合搜索工具，不托管、不存储、不索引也不分发任何第三方链接、文件或受版权保护的内容。所有搜索规则与检索目标均由用户自行配置或导入，请仅将本工具用于合法合规的公开信息、开源项目与个人授权资料检索。
